# Ипотека — мод для Minecraft Forge 1.20.1 (Java 17)

## Как собрать
1. Скачай Forge MDK 1.20.1 (47.x): https://files.minecraftforge.net/ (версия 1.20.1, кнопка Mdk).
2. Распакуй MDK, удали из него `src/` и `gradle.properties`.
3. Скопируй сюда из этого архива папку `src/` и файл `gradle.properties`.
4. Нужна Java 17. Запусти `gradlew build` (Windows: `gradlew.bat build`), jar появится в `build/libs/`.
   Проверка в игре: `gradlew runClient`.
5. Положи jar в папку `mods` Forge 1.20.1.

## Механики
- Закладная плита (крафт: 4 железных слитка, 4 изумруда, золотой блок в центре): поставил, и участок 25x25 оформлен в ипотеку.
  Взнос 20 изумрудов, остаток 76 изумрудов в кредит на 12 месяцев.
- Месяц = 3 игровых дня. Платёж списывается изумрудами из инвентаря.
- Ключевая ставка меняется раз в 4 месяца (4-24%). Плавающая ипотека пересчитывается сама, фиксированная дороже на 1.5%.
- Кредитный рейтинг 300-850: влияет на надбавку банка. Платёж в срок +5, просрочка -40, погашение +30, арест -150.
- Просрочка: пеня и коллекторы (виндикаторы). 3 просрочки подряд: арест участка, строить там нельзя никому. Через 4 месяца защита снимается.
- Чужой участок защищён от ломания, строительства и взрывов. Плиту нельзя сломать, пока ипотека не погашена.
- Команды: /mortgage help | status | rate | pay <N> | refinance <6-24> <fixed|floating>

## Сборка jar без установки Java (через GitHub)
1. Создай аккаунт на github.com и новый репозиторий (New repository, можно приватный).
2. Распакуй этот архив и загрузи всё содержимое в репозиторий (Add file, Upload files). Папка `.github` должна загрузиться тоже.
   Если она не загрузилась: Add file, Create new file, в имени файла напиши `.github/workflows/build.yml` и вставь туда содержимое этого файла из архива.
3. Открой вкладку Actions. Сборка стартует сама через пару секунд (или кнопка Run workflow).
4. Когда появится зелёная галочка, открой запуск, внизу в Artifacts скачай `mortgage-mod-jar`. Внутри zip лежит готовый jar.
5. Кинь jar в папку `mods` у Forge 1.20.1.
